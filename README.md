# 漫域音乐 MANYU MUSIC

漫域音乐是一款原生 macOS 本地音乐播放器，使用 SwiftUI、AVFoundation 和 MediaPlayer 构建。以本地资料库为核心，提供歌曲、专辑、艺术家、文件夹、歌单浏览、31 段参数均衡器、实时频谱、双语歌词、播放统计、重复歌曲检测等能力。

当前版本为 **v1.11.0-beta1（内部测试版）**，最新稳定版为 [v0.5](https://github.com/jader12138/ManYu_Music/releases/tag/v0.5)。完整版本线见 [Releases](https://github.com/jader12138/ManYu_Music/releases)。

## 下载安装

在 [GitHub Releases](https://github.com/jader12138/ManYu_Music/releases) 下载最新的 `ManyuMusic-<版本>.dmg`，双击挂载后把「漫域音乐」拖入「应用程序」文件夹即可使用。

需要 **macOS 14 或更高版本**的 **Apple 芯片（arm64）Mac**（不支持 Intel Mac）。

应用为本地 ad-hoc 签名、未经过 Apple 公证：首次打开若系统提示「无法验证开发者」，请在应用图标上点**右键 → 打开**确认一次，或前往「系统设置 → 隐私与安全性」点击「仍要打开」。

## 主要功能

### 播放与资料库

- 支持 MP3、M4A、AAC、FLAC、WAV、AIFF、CAF 等 macOS 可解码格式
- 支持导入单个文件或整个文件夹，并支持拖拽导入
- 提供歌曲、专辑、艺术家和文件夹四种浏览方式
- 点击播放条或播放页的歌手名可直接进入艺术家详情页，查看该艺术家全部歌曲
- 提供最近添加、最近播放、我喜欢和播放历史
- 支持新建、重命名和删除歌单，并管理歌单歌曲
- 支持全拼与首字母拼音检索，搜索框文字配色修复
- 支持收藏、排序（标题/专辑/时长列头点击排序）、在访达中显示和歌曲信息查看
- 歌曲信息弹层显示比特率（KBPS）、采样率（Hz）、声道等音频参数
- 支持播放队列、下一首播放、随机播放、列表循环和单曲循环
- 支持睡眠定时，以及 macOS 媒体键和系统"正在播放"面板
- 自动保存资料库、音量、队列和上次播放状态
- 启动时自动扫描已添加文件夹，发现新歌自动入库
- 重复歌曲检测：按标题/歌手/专辑/时长判定，逐组选择保留曲目，仅隐藏不删文件

### 均衡器与音效

- 31 段参数均衡器（20Hz~20kHz，±6dB，Q 值可调，35 预设 + 自定义）
- 音效增强页签：8 项频率调节 + 3 项空间效果 + 2 项输出控制
- 实时山峰频谱：384 点对数频轴采样，180pt 高，五等分水平参考线
- Gapless 无缝播放与 Crossfade 淡入淡出（3~12 秒，默认关闭）

### 歌词与播放界面

- 支持音频内嵌歌词、同名 LRC 歌词和逐句时间轴高亮
- 支持双语歌词：相同时间戳的原文/译文自动合并，右下角「译」开关控制显示
- 支持调整歌词字号、字体和颜色
- 歌词切换效果：渐隐、像素溶解、从左揭开、从右推入等多种过渡
- 播放页根据专辑封面提取主色，并同步调整背景与控制区域
- 首页显示当前专辑封面、实时歌词和播放状态
- 支持从首页平滑进入沉浸式播放界面
- 切歌时封面缩放渐入过渡，同步缓存命中消除视觉跳变

### 播放统计

- 今天、本周、本月、本年四个维度的歌曲/专辑/艺术家排行
- 内嵌主窗口页面，跟随昼夜主题

### 外观与系统集成

- 主题跟随系统自动切换，或手动选择白天/夜间模式
- 外观设置提供真实界面预览缩略图（132×88，选中蓝色描边）
- 提供自动、深色、浅色三档 App 图标选择
- 支持播放时在 Dock 显示专辑封面，带透明安全边距和状态角标
- Dock 图标右键菜单：当前歌曲名与歌手·专辑，播放/暂停、上一首、下一首
- 菜单栏迷你播放器：封面 + 歌名/艺人 + 可拖动进度条 + 三键控制
- 菜单栏实时歌词：状态栏常驻自定义播放图标与固定宽度歌词区（逐句更新），左/右键点击图标弹出菜单（可在设置中开关）
- 底部播放条亚克力材质背景，封面亚克力包边
- 主窗口固定启动位置与尺寸（1060×706）
- 可设置关闭窗口后继续后台播放

### 音量控制

- 播放条喇叭 + 常驻横向滑条，点击喇叭可静音/恢复
- 静音时滑条填充条和拇指平滑变灰（0.18 秒颜色过渡）
- 播放页点击喇叭从右方弹出横向滑块
- 喇叭图标切换带缩小淡出 + 放大淡入弹簧动画

### 元数据与性能

- 原生解析 FLAC、Vorbis Comment 和 PICTURE 内嵌元数据
- 异步读取标题、艺人、专辑、时长和封面
- 封面加载双优先级池（可见行 urgent / 预取 prefetch），快速滑动封面秒出
- 滚动窗口预取：行进入可见区后 120ms 防抖预解码前后范围封面
- 播放进度条改用 10Hz 局部刷新，播放中 CPU 约 4%，暂停接近 0%

## 系统要求

- macOS 14 或更高版本
- Apple 芯片（arm64）
- Swift 5.10 或兼容工具链（仅构建时需要）
- 播放能力跟随 macOS AVFoundation；OGG、WMA 等格式需要系统解码器支持

## 运行

```bash
swift run
```

## 构建应用

```bash
./scripts/build-app.sh
```

生成的应用位于 `dist/漫域音乐.app`，可双击运行，也可以拖入「应用程序」目录。`VERSION` 文件驱动版本号：允许带预发布后缀（如 `1.0.0-beta1`），系统版本号取 `-` 之前的三段数字，完整版本号写入 Bundle 供设置页显示「内部测试版」标识。

## 快捷键

- `⌘P`：播放或暂停
- `⌘→`：下一首
- `⌘←`：上一首
- `⌘⌥→`：快进 10 秒
- `⌘⌥←`：后退 10 秒

## 项目结构

```text

  Models/                  数据模型（Track、Album、Artist、Playlist 等）

  Support/                 主题系统、拼音索引、播放器菜单规格
Resources/                 图标素材和 Info.plist
scripts/build-app.sh       macOS App 打包脚本
docs/releases/             按版本永久保存的发布记录
docs/VERSION_CONTROL.md    Git 与发布流程
CHANGELOG.md               面向开发过程的简明更新日志
VERSION                    当前版本号
```
