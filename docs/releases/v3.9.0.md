# 漫域音乐 v3.9.0

- 发布状态：已发布
- 发布日期：2026-09-13
- Git 标签：`v3.9.0`
- 对应 `VERSION`：`3.9.0`
- 上一稳定版本：`v3.8.0`
- 发布分支：`codex/v3.9.0-release`

## 摘要

本次版本更新设置流程、播放主界面、首页交互、Dock 专辑封面、歌曲列表和发布文档体系，并加入播放状态恢复与歌词视觉强化。

## 用户可见更新

### 新增

- 设置中新增“记住上次播放状态”，重启后恢复歌曲、队列、进度和音量
- 设置界面改为主窗口内嵌页面，不再打开独立设置窗口
- 增加深色、浅色两套 App 图标资源
- 设置中增加“自动 / 深色 / 浅色”三档 App 图标选择
- 用户歌单管理流程和设置页导入入口
- 首页“最近添加”区域
- 首页问候语增加中文诗句、简短问候和英文短句轮换

### 改进

- 设置界面统一为主界面一致的白蓝玻璃卡片风格
- 应用菜单和快捷键设置入口切换为主窗口内设置页面
- 底部播放栏缩为 72pt，并缩小专辑封面和播放按钮
- 主界面移除“导入”和“添加音乐”按钮，导入统一放入设置
- 顶部“漫域音乐”品牌和图标支持点击返回首页
- 首页歌词摘要固定展示 4 行，并优化中段截取和制作人员过滤
- 首页播放按钮移入专辑封面内部，并根据封面主色自动配色
- 首页副标题只显示歌曲总数
- 放大播放主界面左侧封面与下方控制条
- 优化歌词垂直位置、上下渐隐效果和当前行强调
- 调整 Dock 专辑封面留白，缩小封面并扩大亚克力背板的可视边框
- Dock 专辑封面增加窄幅玻璃背板，兼容不同尺寸封面并遮挡白边
- Dock 专辑封面角标改为封面取色的玻璃亚克力样式，并放大播放或暂停符号
- Dock 基础图标和应用侧栏图标跟随图标设置
- FLAC 等格式标签移动到歌曲信息右侧
- 启动焦点默认落在播放按钮，未编辑搜索框时按空格可播放或暂停
- 日常开发改为维护一条 `codex/*` 工作分支，完成一到两项功能后再合并到 `main`

### 修复

- 切歌时保留上一张封面，消除 Dock 图标闪回默认图标
- 修复歌曲列表顶部大块空白，列表首行紧跟表头
- 首页“最近播放”在当前停留期间保持顺序，不再随切歌跳动
- 首页歌词竖线与文本严格等高，避免底部空白
- 修复侧栏品牌图标与 App 图标不一致
- 修复 README 被源码内容错误覆盖的问题，并重建项目说明

## 技术变更

- `AudioPlayer` 增加播放状态持久化与恢复
- 歌曲列表由旧 `List` 布局改为受控高度的 `ScrollView`、`LazyVStack`
- 歌词时间轴增加分段遮罩、距离渐隐和当前行渐变强调
- 设置模型和应用图标管理逻辑拆分
- 新增按版本独立保存的发布记录、历史版本归档和发布模板
- `AGENTS.md` 与 `docs/VERSION_CONTROL.md` 更新开发、合并和发布规则

## 兼容性与迁移

- 最低系统版本仍为 macOS 14
- 原有资料库、歌单、收藏和播放历史继续使用现有存储格式
- 首次启用“记住上次播放状态”后，会在退出或状态变化时写入播放状态
- 历史 `CHANGELOG.md` 和旧版本文档全部保留

## 验证

- `swift build -c release` 通过

- `codesign --verify --deep --strict` 通过
- 手工检查歌曲列表、设置页、播放栏、Dock 封面和歌词主界面
- 合并到 `main` 后重新执行 Release 构建和应用签名验证

## 已知问题与后续

- 后续开发继续使用单一 `codex/*` 工作分支，完成后经用户批准再合并主线
