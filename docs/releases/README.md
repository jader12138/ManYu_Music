# 发布记录

本目录保存漫域音乐的长期版本档案。`CHANGELOG.md` 用于快速查看更新，本目录用于保存每次较大更新合并和正式发布后的完整记录。

## 归档规则

- 每个正式版本使用独立文件：`v主版本.次版本.修订版本.md`
- 尚未正式分配版本号的内容记录在 `unreleased.md`
- `main` 合并较大功能后，必须同步更新 `unreleased.md`
- 正式发布时，将 `unreleased.md` 复制为对应版本文件，并补齐版本号、日期、提交和标签
- 历史版本文件永久保留，不得删除、重命名或覆盖
- 历史内容如需纠正，只能在原文件末尾追加“修订记录”
- 新版本发布后，将 `unreleased.md` 重置为只包含下一版本尚未发布的内容

## 必须记录的内容

每份版本文档至少包含：

1. 版本摘要和发布日期
2. 用户可见的新增、改进和修复
3. 影响维护、兼容性或发布方式的技术变更
4. 构建、应用包和签名验证结果
5. 对应提交、合并提交和 Git 标签
6. 已知问题、风险和未完成事项

新文档可以从 [模板](TEMPLATE.md) 开始。
